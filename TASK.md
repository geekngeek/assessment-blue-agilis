# Senior Software Engineer Take Home Assessment

## Objective

Create a to-do application in TanStack Start using server functions and a database of your
choosing (can be local in the browser with TanStack DB and RxDB, mongodb, etc. but you'll be
responsible for hosting if you go with a db outside of a browser based db).

## Application Acceptance Criteria

1. Create to-do's
2. List to-do's
3. Update to-do's
4. Delete to-do's
5. Search for to-do's
6. Filter by status (to-do, in progress, and done)
7. Use keyboard shortcuts with a command palette

## Deliverables

- A URL to where the functioning app is hosted (doesn't need to be a custom domain; default
  Vercel or other platform hosted URL suffices)
- GitHub repo complete with a `README.md`
- A shareable link to how you planned this with your AI coding tool of choice (a public link to
  Claude, ChatGPT, etc. works)

## Timebox

48 hours from receipt.
